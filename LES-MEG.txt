# NIRO v8.3 – strekkodeoppslag på web fikset

Endret:
- Open Food Facts-oppslaget bruker API v2, som fungerer bedre i nettleser/PWA.
- Fjernet forsøk på å sette User-Agent fra nettleseren.
- Bruker Accept: application/json.
- Prøver både world.openfoodfacts.org og no.openfoodfacts.org.
- Egne produkter med samme strekkode brukes først.
- Alle tidligere feilrettinger og NIRO-logoen er beholdt.

Installer:
1. Kopier alle filer og mapper inn i prosjektmappen.
2. Velg "Erstatt filene i mål".
3. Test lokalt med: npx expo start --web -c
4. Publiser med:
   git add .
   git commit -m "Fiks strekkodeoppslag på web"
   git push
