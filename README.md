# Norsk Kaloriapp – første prototype

En enkel Expo/React Native-prototype med:

- daglig kalorimål
- oversikt over kalorier og protein
- søk i en liten eksempel-liste med norske matvarer
- legg til og fjern mat fra dagens matdagbok

## Start lokalt

1. Installer Node.js LTS.
2. Installer Expo Go på mobilen.
3. Åpne terminal i denne mappen.
4. Kjør:

```bash
npm install
npx expo start
```

5. Skann QR-koden med Expo Go.

## Begrensninger i denne versjonen

- Data lagres ikke etter at appen lukkes.
- Matvarelisten er bare testdata.
- Ingen bruker eller innlogging.
- Ingen database eller strekkodeskanning ennå.

## Neste tekniske steg

1. Lokal lagring av dagbok og kalorimål.
2. Supabase-database.
3. Import av matvarer.
4. Egne porsjoner og måleenheter.
5. Strekkodeskanning.
